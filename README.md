# 🦀 AcadémIA Pro

Investigador académico con **WebAssembly compilado en Rust**, Multi-IA con fallback automático, Core 403M auto-evolutivo y Agent-Reach.

## ✨ Características

- 🦀 **WASM Rust real**: 160 KB compilado desde Rust, 13 funciones nativas
- 🔄 **Multi-IA**: Mistral AI → OpenRouter (fallback automático, 7 modelos)
- 🧬 **Core 403M**: Auto-evolución cada minuto, memoria persistente
- 🔌 **Agent-Reach**: GitHub, Reddit, Wikipedia
- 📚 **12+ Fuentes académicas**: Crossref, OpenAlex, Semantic Scholar, arXiv
- 🌐 **Multilingüe**: 6 idiomas con detección automática
- 📊 **Análisis en tiempo real**: Palabras, citas, legibilidad, riqueza
- 📝 **APA 7**: Bibliografía generada automáticamente
- ⚡ **50x más rápido** que JavaScript puro
